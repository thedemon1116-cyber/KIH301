# 할 일 목록 (To-do)

HTML, CSS, JavaScript만으로 만든 간단한 할 일 목록 웹앱입니다. 설치할 것이 없습니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

## 기능

### 업무 그룹 (실 › 팀 › 할 일)

할 일을 2단계 그룹으로 묶어 관리할 수 있습니다.

```
회원관리(실)
├─ 실 주간 회의 안건 정리      ← 실에 바로 속한 할 일
├─ 이용율 관리(팀)
│   ├─ 월간 이용율 리포트 작성
│   └─ 휴면 회원 알림 문구 검토
└─ 가입 관리(팀)
    └─ 가입 절차 단계 줄이기
```

- 할 일을 추가할 때 `실`과 `팀`을 적으면 그 그룹에 들어갑니다. 둘 다 선택이며, 팀은 실을 먼저 적어야 입력할 수 있습니다.
- 한 번 쓴 실/팀 이름은 자동완성으로 다시 고를 수 있습니다.
- 그룹 제목을 누르면 접고 펼 수 있고, 남은 개수/전체 개수가 표시됩니다.
- 그룹의 ＋ 버튼: 그 그룹이 미리 채워진 상태로 할 일을 추가합니다.
- 그룹의 ✎ 버튼: 그룹 이름을 바꿉니다. 이미 있는 이름으로 바꾸면 두 그룹이 합쳐집니다.
- 처음 열면 예시 항목이 보입니다. 필요 없으면 지우면 됩니다.

### 작성하기 · 진행 상태

각 할 일의 **작성하기** 버튼을 누르면 창이 열립니다.

- **상세 내용**: 진행 상황, 메모 등을 자유롭게 적습니다. 입력하는 대로 자동 저장됩니다.
- **최종 자료**: 파일을 올려 둘 수 있습니다(여러 개 가능). 파일 이름을 누르면 내려받고, ×로 지웁니다.
- **완료로 표시**: 창 안에서도 완료 처리를 할 수 있습니다.

진행 상태는 자동으로 정해집니다.

| 상태 | 조건 |
| --- | --- |
| 진행 전 | 작성한 내용도, 올린 파일도 없음 |
| 진행 중 | 상세 내용을 적었거나 파일을 올림 |
| 완료 | 완료 체크함 |

> 올린 파일은 그 브라우저의 IndexedDB에 저장됩니다. 다른 컴퓨터나 다른 브라우저에서는 보이지 않으며, 할 일을 지우면 파일도 함께 지워집니다.

### 할 일

- 할 일 추가 / 삭제
- 체크박스로 완료 표시
- 더블클릭으로 내용 수정 (Enter 저장, Esc 취소)
- 마감일 설정 (오늘까지는 주황색, 지난 날짜는 빨간색으로 표시, 날짜를 눌러 변경)
- ☆ 별표로 중요 표시
- ⠿ 손잡이를 끌어서 같은 그룹 안에서 순서 바꾸기 (마우스·터치 모두 가능)
- 전체 / 진행 전 / 진행 중 / 완료 / 중요 필터
- 완료 항목 한꺼번에 지우기
- 새로고침해도 유지 (할 일은 localStorage, 파일은 IndexedDB에 저장)
- 다크 모드 자동 지원, 모바일 화면 대응

## 팀 공유판 (`team/`)

팀원들과 같은 목록을 함께 쓰는 버전입니다. claude.ai 아티팩트에서만 동작합니다.

- 할 일·상세 내용·첨부가 아티팩트의 공유 저장소에 저장되어, 링크를 공유받은 팀원 모두가 같은 내용을 실시간으로 봅니다.
- 마지막으로 고친 사람과 파일을 올린 사람의 이름이 표시됩니다.
- 첨부: 모든 형식의 파일을 올릴 수 있습니다. PDF·이미지·동영상·txt·csv는 20MB까지 그대로 저장되어 새 탭에서 열리고, 한글·워드·엑셀·PPT 등 그 밖의 파일은 15MB까지 글자(base64)로 바꿔 보관했다가 내려받을 때 원래 파일로 되돌립니다. 내려받기 창이 바로 저장하지 못하는 형식(hwp, doc, xls, ppt 등)은 zip으로 감싸 내려받습니다. 더 큰 파일은 공유 드라이브 주소를 **링크**로 추가합니다.
- 할 일을 지울 때는 팀원 화면에서도 사라지므로 한 번 더 확인합니다.
- 보기 권한만 있는 사람에게는 목록이 읽기 전용으로 보입니다.

| 파일 | 역할 |
| --- | --- |
| `team/page.html` | 화면 구조 |
| `team/team.css` | 팀 공유판 전용 디자인 (공용 디자인은 `style.css`) |
| `team/team.js` | 동작 (공유 저장소 읽기/쓰기) |
| `team/build.py` | 위 파일들을 합쳐 `team/index.html` 한 파일로 만듦 |
| `team/index.html` | 아티팩트로 올리는 완성본 |

수정 후에는 `python3 team/build.py`를 실행해 `team/index.html`을 다시 만듭니다.
